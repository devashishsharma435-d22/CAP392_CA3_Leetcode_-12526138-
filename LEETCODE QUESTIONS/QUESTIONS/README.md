# CAP392 CA3 - LeetCode Java Solutions

This repository contains the 16 Java solutions for the CAP392 CA3 assignment.

## Folder structure
- `Easy/` - Questions 01 to 09
- `Medium/` - Questions 10 to 14
- `Hard/` - Questions 15 to 16

## How to use
Each file contains a LeetCode-compatible `Solution` class. Open the corresponding problem on LeetCode, choose Java, and paste the code from the matching file.

## Important
The assignment sheet lists LeetCode #233 as "Number to one digit". The official LeetCode #233 title is **Number of Digit One**. Confirm with your faculty that #233 is the intended problem before final submission.

Prepared for CAP392 Java Programming CA3.
